AmsterLearn: Defend your Knowledge

AmsterLearn este o aplicație web inovatoare de tip Tower Defense care transformă sesiunile de studiu plictisitoare într-o experiență de gamification captivantă. Utilizatorii își încarcă materialele de curs, iar inteligența artificială generează provocări în timp real pentru a construi și apăra o metropolă digitală inspirată de Amsterdam.
Tehnologii Utilizate (AI-Powered Stack)

    Frontend: React.js cu Vite (pentru viteză și performanță).

    Backend: Node.js / Python FastAPI (pentru procesarea documentelor).

    AI Engine: Ollama (Llama 3 / Phi-3) rulate local pentru generarea quiz-urilor.

    Bază de date: PostgreSQL / Supabase.

    DevOps: GitHub Actions (CI/CD) și Docker.
